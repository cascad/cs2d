# Как перенатянуть («reskin») персонажа

Кратко: персонаж — это **спрайт-атлас по направлениям**. Меняешь PNG-листы (и,
если изменилась сетка, пару констант) — и модель новая. Логика игры (движение,
коллизия, способности) от внешнего вида не зависит.

## 1. Где лежат ассеты

```
client/assets/knight/
  Idle.png     # покой
  Walk.png     # ходьба/бег
  Melee.png    # удар (одноразовая)
  Rolling.png  # рывок/перекат (одноразовая)
  Run.png      # (сейчас не используется)
```

Каждый лист — это **сетка кадров**: по горизонтали кадры анимации, по вертикали
направления (8 штук). Текущие листы: `1920×1024`, то есть **15 столбцов × 8 строк**,
клетка **128×128**.

- Строка = направление взгляда (8 направлений).
- Столбец = кадр анимации (0..14).

## 2. Самый простой случай — та же сетка

Если новый персонаж нарисован в **той же сетке** (15×8, клетка 128×128, те же
направления по строкам) — просто **замени файлы** `Idle/Walk/Melee/Rolling.png`.
Больше ничего править не нужно.

Требования к листам, чтобы «легло» без правок кода:
- одинаковый размер клетки и одинаковое число столбцов/строк во ВСЕХ четырёх листах;
- строки направлений в порядке (прочитано из текущих листов, кадр Walk frame7):

  | строка | направление (экран) |
  |--------|---------------------|
  | row 0  | Запад (влево)       |
  | row 1  | Юго-Запад           |
  | row 2  | Север (спиной)      |
  | row 3  | Северо-Запад        |
  | row 4  | Восток (вправо)     |
  | row 5  | Северо-Восток       |
  | row 6  | Юг (лицом к камере) |
  | row 7  | Юго-Восток          |

## 3. Если сетка другая (число кадров/клетка)

Открой `client/src/systems/iso.rs`, поправь верхние константы:

```rust
pub const KNIGHT_COLS: usize = 15;  // кадров в строке (столбцов)
pub const KNIGHT_ROWS: usize = 8;   // направлений (строк)
pub const KNIGHT_CELL: u32  = 128;  // размер клетки в px (квадрат)
```

Они задают разбиение листа на кадры (`TextureAtlasLayout`). Лист должен быть
ровно `KNIGHT_CELL*KNIGHT_COLS` в ширину и `KNIGHT_CELL*KNIGHT_ROWS` в высоту.

Если в новой анимации **другое число кадров в idle/walk и в action** — сейчас код
берёт `KNIGHT_COLS` кадров для всех. При разном числе кадров на состояние
понадобится хранить длину на каждое состояние (скажи — добавлю поле).

## 4. Если строки идут в другом порядке / «перёд» смотрит не туда

Поворот спрайта к курсору считает `knight_row()` в `iso.rs`. Если новый лист
повёрнут (персонаж смотрит не туда, куда целишься) — крути ОДНО число:

```rust
pub const KNIGHT_ROW_OFFSET: i32 = 0; // ±1 = поворот выбора строки на 45°
```

- Перёд «убегает» по часовой → уменьшай (`-1`, `-2`…).
- Против часовой → увеличивай.
- Если ровно «спиной к курсору» (180°) → поставь `4`.

Если у листа **другая раскладка строк** (например по часовой, а не как в таблице
выше) — это тоже лечится `KNIGHT_ROW_OFFSET` (поворот) либо, в крайнем случае,
переставить соответствие в `knight_row` (там одна формула `(4 - idx8 + offset)`).

## 5. Куда какие листы привязаны (состояния)

`iso.rs`, ресурс `KnightAnims` и метод `sheet()`:

```rust
AnimState::Idle   => Idle.png      // зациклено, LOOP_FPS
AnimState::Walk   => Walk.png      // зациклено, по факту движения
AnimState::Attack => Melee.png     // одноразово, ACTION_FPS
AnimState::Dash   => Rolling.png   // одноразово, катится в сторону рывка
```

Загрузка путей — в `setup_iso()`:

```rust
idle:    asset_server.load("knight/Idle.png"),
walk:    asset_server.load("knight/Walk.png"),
melee:   asset_server.load("knight/Melee.png"),
rolling: asset_server.load("knight/Rolling.png"),
```

Хочешь другую папку/имена — меняешь эти 4 строки (и положи файлы туда же).

## 6. Размер и «ноги» на земле

Там же в `iso.rs`:

```rust
pub const ISO_ACTOR_PX: f32   = 150.0;  // экранный размер спрайта (масштаб модели)
pub const KNIGHT_ANCHOR_Y: f32 = -0.30; // якорь: куда попадают «ноги» (точка WorldPos)
```

- `ISO_ACTOR_PX` — крупнее/мельче персонаж.
- `KNIGHT_ANCHOR_Y` — если модель «парит» или «утоплена» в пол, подвинь якорь
  (отрицательное — ноги ниже центра канваса). Под ногами рисуется кольцо-маркер
  и над головой — полоска HP; они привязаны к этой точке.

## 7. Скорость анимации

```rust
const LOOP_FPS: f32   = 12.0; // idle/walk
const ACTION_FPS: f32 = 24.0; // удар/рывок (играются один раз)
```

## 8. Что НЕ зависит от внешнего вида

- Движение/коллизия/способности — в `protocol` (`abilities.rs`, `geom.rs`,
  `level.rs`) и на сервере. Менять при reskin не нужно.
- Спавн игрока — `client/src/systems/network.rs::spawn_player` (берёт листы из
  `KnightAnims`); править нужно, только если меняешь набор листов/состояний.

## Чек-лист «быстрый reskin»
1. Нарисуй 4 листа в сетке 15×8 (клетка 128) с тем же порядком направлений.
2. Положи в `client/assets/knight/`, перезапиши старые.
3. Запусти. Если смотрит не туда — подвинь `KNIGHT_ROW_OFFSET`.
4. Если «парит»/мелкий — подвинь `KNIGHT_ANCHOR_Y` / `ISO_ACTOR_PX`.
